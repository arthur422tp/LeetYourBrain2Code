# v0.2.0 Case-to-Case Behavioral Diff Manual Acceptance

This note records the real-browser acceptance evidence for the first-divergence
slice. It contains only public problem identifiers and technical observations;
source code, testcase values, account data, and trace payloads are intentionally
omitted.

## Scope notes

- Binary Search exercises the required loop-heavy public flow.
- Recursive and exception-vs-return browser flows were not added to this
  manual note because the primary acceptance path was sufficient to validate
  the release gate; deterministic recursive, termination, ambiguity, and
  partial-evidence scenarios are covered by the automated fixture and
  integration suites.
- Ordered multi-divergence collection, navigation, and filters remain deferred
  to v0.2.x as documented in the design spec.
